<h1>Quizz - Android Quiz App</h1>

<h2>📱 Overview</h2>
<p><strong>Quizz</strong> is an Android app that lets users <strong>play predefined quizzes</strong>, <strong>create and customize their own</strong>, and even <strong>share custom quizzes with friends</strong> using a unique quiz ID. It features a scoring system and a clean, user-friendly interface for an engaging quiz experience.</p>
<blockquote><strong>Note:</strong> This project is still under development. More features are coming soon.</blockquote>

<hr/>

<h2>🚀 Features</h2>
<ul>
  <li><strong>Predefined Quizzes:</strong> Play quizzes available within the app across various topics.</li>
  <li><strong>Custom Quiz Creation:</strong> Users can create and manage their own quizzes with custom questions and answers.</li>
  <li><strong>Quiz Sharing with Friends:</strong> Share your custom quiz with friends using a unique quiz ID, and let them play your quiz directly.</li>
  <li><strong>Scoring System:</strong> Real-time score tracking and display after each quiz.</li>
  <li><strong>User-Friendly Interface:</strong> Minimal and intuitive UI designed for smooth navigation and quick interactions.</li>
</ul>

<hr/>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><strong>Language:</strong> Java</li>
  <li><strong>Platform:</strong> Android Studio</li>
  <li><strong>Data Handling:</strong> Arrays (currently), with planned support for Firebase/Firestore</li>
</ul>

<hr/>

<h2>📌 Roadmap (Planned Features)</h2>
<ul>
  <li>Firebase or Firestore integration for storing quizzes and scores online</li>
  <li>Leaderboards and time-based challenges</li>
  <li>User authentication for custom quiz tracking</li>
  <li>Timer-based quiz mode</li>
  <li>Bookmark or favorite quizzes</li>
